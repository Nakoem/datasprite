## 失败详情

### q12 2025年每个月的销售总额

- 类别：时间趋势
- 原因：结果集不一致
```sql
SELECT SUBSTRING(CAST(date_id AS CHAR), 5, 2) AS 月份, SUM(order_amount) AS 销售总额 FROM fact_order WHERE date_id >= 20250101 AND date_id <= 20251231 GROUP BY SUBSTRING(CAST(date_id AS CHAR), 5, 2) ORDER BY 月份
```

## 已知局限

- **q12 属对比误判（非系统答错）**：该题 12 个月销售额数值全对，仅「月份」分组键的
  标签格式在不同运行间漂移（`date_id DIV 100` → 202501、`DATE_FORMAT('%Y-%m')` →
  '2025-01'、`SUBSTRING(CAST(date_id AS CHAR),5,2)` → '01'），结果集对比对分组键格式敏感，
  无法追平这个移动靶。判定逻辑刻意保持严格，避免掩盖真实错误；q12 保留为已知盲区，
  后续可考虑对时间维度键做规范化后对比。
- **评测会受 LLM 瞬时连接抖动影响**：链路执行遇 Connection error 时自动重试（≤2 次），
  逻辑错误不重试；但极端抖动下仍可能误判，重跑可复核。
